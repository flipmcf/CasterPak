How to Throttle Your Browser to Test Bitrate Switching

Chrome (recommended — full HUD): DevTools (F12) → Network tab → Throttling dropdown → pick "Slow 3G". Watch the yellow MEASURED bitrate and the ▶ marker drop to 360p, then clear throttling and watch them climb back. Give it a few seconds after each change — adaptation reacts at the next segment boundary, not instantly.

Firefox: DevTools → Network → Throttling dropdown.

Safari: Develop menu → Network Throttling. Note: Safari plays HLS natively, so the VHS engine isn't in play and the HUD can only show decoder resolution — use Chrome for the full readout.

Run this against the Docker stack, not flask dev mode. In dev mode nginx isn't there to serve the segments, they come back zero-byte, nothing ever takes long enough to download to trigger a downshift, and the player will sit on one level forever.
