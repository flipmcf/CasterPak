How to Throttle Your Browser to Test Bitrate Switching

Chrome:

  1. Open Developer Tools (Cmd+Opt+I on Mac, Ctrl+Shift+I or F12 on Windows).
  2. Go to the "Network" tab.
  3. Find the "Throttling" dropdown, which is usually set to "No throttling".
  4. Choose a slower connection speed, like "Slow 3G".

Firefox:

  1. Open Developer Tools (Cmd+Opt+I on Mac, Ctrl+Shift+I or F12 on Windows).
  2. Go to the "Network" tab.
  3. Find the "Throttling" dropdown on the right side of the toolbar.
  4. Choose a slower connection speed.

Safari:

  1. Enable the "Develop" menu in Safari's preferences (Preferences > Advanced > "Show Develop menu in menu bar").
  2. In the "Develop" menu, go to "Network Throttling" and select a profile.
